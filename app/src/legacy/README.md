# Historical Xelo runtime sources

These files were moved from `app/src/main/java` when the active build switched to the installed Bedrock game and resource packs. This directory is not a Gradle source set for the active app. The native sources, submodule pins and support modules remain in the repository for reference. They are not a tested Android Bedrock 26.62 runtime. The active configuration and its verification steps are in [the Android Bedrock guide](../../../docs/android-bedrock.md).
